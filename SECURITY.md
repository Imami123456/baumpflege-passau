# Security Policy

## Supported Versions

We release patches for security vulnerabilities for the current active release.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within this repository, please notify us responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to [security@baumpflege-passau.de](mailto:security@baumpflege-passau.de) with details of the vulnerability.
3. Include:
   - A description of the issue.
   - Steps or proof-of-concept to reproduce the behavior.
   - The affected component or URL.

### Response Time
We will acknowledge receipt of your vulnerability report within 48 hours and provide an assessment and timeline for a patch.
